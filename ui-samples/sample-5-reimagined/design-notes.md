# ABC 学习助手 · Nordic Calm 方向

## 选择

选用 `moodboard/direction-3-nordic-calm.jpg`。

## 原因

- 学习场景需要长时间盯着屏幕，浅暖底色比深色霓虹更耐看。
- 鼠尾草绿只作为状态和进度色，避免变成单一绿色主题。
- 标题使用宋体，工具界面使用系统无衬线，形成“学习内容 / 工具操作”的层级差。
- 用分隔线和留白组织结构，不把每个区块都做成浮动卡片。
- 抽屉保持 440px，折叠后只留一个低干扰气泡。

## 结构落地

- 折叠态：右下气泡，进度环 + 运行状态点。
- 抽屉头部：产品名、本地运行状态、运行中标记、关闭。
- 当前章节：课程标题、章节信息、进度、倍速/剩余时间/任务点数。
- 当前任务：播放状态、时间、倍速切换、自动下一节、防卡死。
- 任务进度：竖向时间线，包含完成、进行中、待处理、未开始。
- 章节测验：当前题目、答案、来源与置信度、AI 补漏与查看解析入口。
- 运行日志：深色低对比终端块，只保留最近三条。
- 设置：抽屉内二级层，不离开当前课程上下文。

## 状态覆盖

- 折叠 / 展开
- 运行中
- 任务点阻塞提示
- 题目命中
- 日志清空
- 设置保存

## 约束

- 不修改主 `.user.js`。
- 不依赖外部图片。
- 桌面优先，移动端抽屉全宽。
