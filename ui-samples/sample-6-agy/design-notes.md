# Sample 6 · AGY 设计说明

## 方向

选用 `direction-3-nordic-calm.jpg`：浅暖米白底、鼠尾草绿强调、低饱和边框与柔和阴影。目标不是通用后台，而是"安静的桌面学习伴侣"——信息密度适中，长时间阅读不刺眼。

## 色板与字体

| Token | 值 | 用途 |
|---|---|---|
| `--clr-bg` | `#f5f0eb` | 页面底色 |
| `--clr-surface` | `#ede6dc` | 卡片表面 |
| `--clr-surface-2` | `#e4dcd0` | 次级表面 / 轨道 |
| `--clr-sage` | `#7a9e8e` | 主强调 |
| `--clr-sage-dark` | `#4d7b6a` | 强调文字 / 当前态 |
| `--clr-text` | `#3b3530` | 主文字 |
| `--clr-text-muted` | `#7a6f66` | 次要文字 |

字体使用系统栈（Segoe UI / system-ui），不加载网络字体；日志用等宽栈（Cascadia Mono / Consolas）。

## 布局

- 参考视口 1440×900；内容列 `max-width: 1040px` 居中，四周 32px 留白。
- 右侧抽屉固定 440px，`translateX(100%)` 收起，展开时内容区加 440px 右外边距。
- 内容区两栏：主列（时间线）+ 330px 侧列（随堂练习 / 运行日志）；视口小于 1200px 时合并为单列。
- 抽屉收起时右下角出现 56px 悬浮气泡，带未读角标；展开后气泡淡出。

## 组件清单

1. **头部**：叶片图标 + 产品名 + 详情面板 / 新建按钮。
2. **课程概览**：课程名、教师、学时、截止时间、62% 环形进度、任务统计。
3. **播放控制条**：章节标签、课时名、时间、可点击进度条、上一节 / 播放暂停 / 下一节、音量、倍速、设置。
4. **异常状态横幅**：播放中断 / 降级提示 + 重连按钮；重连后转为绿色成功态。
5. **任务时间线**：四类节点（已完成 / 进行中 / 未开始 / 作业），带进度、时长、截止时间；支持"全部 / 未完成"筛选。
6. **随堂练习**：题干、四个选项、选中态、提交反馈、题号推进（1/5 → 2/5）。
7. **运行日志**：等宽字体、时间戳、警告色、可清空。
8. **设置层**：三个开关、倍速分段控件、日志保留分段控件、取消 / 保存。
9. **抽屉详情**：当前课程、章节进度、今日学习、连接质量、快捷操作。
10. **Toast / 悬浮气泡 / 背景气泡**：轻量反馈与氛围层。

## 覆盖状态

- 播放中 / 已暂停（按钮图标与日志同步）
- 播放进度增长、点击进度条跳转
- 倍速循环切换（0.75 / 1.0 / 1.25 / 1.5 / 2.0），与设置层同步
- 网络异常 → 重连成功（横幅变色、按钮隐藏、日志追加）
- 答题未选 / 选对 / 选错（三种反馈）
- 设置打开 / 关闭 / 保存（保存后 Toast + 日志）
- 日志清空（保留一条"日志已清空"）
- 抽屉展开 / 收起（头部按钮、气泡、关闭按钮、ESC）
- 时间线"全部 / 未完成"筛选

## 已知限制

- 数据全部为内置模拟，刷新后回到初始状态，没有 localStorage 持久化。
- 播放进度为 1 秒定时器模拟，不对应真实视频；音量条为纯展示。
- `color-mix()` 需要较新的 Chromium / Safari / Firefox；旧内核下部分浅色底会退化。
- 背景气泡为纯装饰，不参与交互；小屏（< 900px）未做专门适配。
- 未接入真实超星页面，也不修改主 userscript。
