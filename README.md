# 学习通-刷课

一个运行在超星学习通页面里的 userscript 学习助手。脚本只使用你自己配置的 OpenAI 兼容模型 API，不内置题库、不依赖第三方搜索服务，密钥只保存在本地浏览器。

> 仅用于你有权访问的课程、测试环境和个人学习辅助。请遵守学校与平台的使用规则。

## 功能

- 三入口悬浮面板：**状态 / 答题 / 设置**
- 迷你态与展开态切换，记住上次状态和位置
- 状态页展示当前章节、任务点、视频进度、最近日志
- 单列答题页：只答题开关、当前题、答案、置信度、答题记录
- 设置首屏只保留：API 地址、API 密钥、模型名、视频倍速、自动提交阈值
- 全局运行开关：关闭后停止自动答题、自动刷新和路由逻辑
- 模型失败仅对网络、429、5xx、超时重试，三次后暂停本会话
- 填答后会校验页面实际选中项；未应用会重试，存在未填题时禁止自动交卷
- 章节弹窗按章节状态机处理，避免无限点击「去学习」

## 安装

1. 安装 ScriptCat、Tampermonkey 或兼容的 userscript 管理器。
2. 下载仓库中的 [`学习通-刷课.user.js`](./学习通-刷课.user.js)。
3. 在脚本管理器中选择“导入脚本”或“安装脚本”。
4. 打开超星学习通课程页面，脚本会在页面右下角/右侧显示悬浮面板。

## 配置

首次使用请进入「设置」填写：

| 配置 | 说明 |
|---|---|
| API 地址 | OpenAI 兼容接口地址，例如 `https://ark.cn-beijing.volces.com/api/v3` |
| API 密钥 | 你的模型 API Key，只保存在本地 |
| 模型名 | 例如 `deepseek-v4.1-flash`、`gpt-4o-mini` |
| 视频倍速 | 播放倍速 |
| 自动提交阈值 | 达到该正确率后自动提交 |

高级设置中还可以调整请求间隔、日志保留和自动交卷等选项。

## 使用

- **状态**：查看当前章节、任务点、视频进度和最近日志。
- **答题**：进入章节测试、作业或考试页面后，脚本会使用模型返回答案；答题页只显示当前题和实际应用结果。
- **设置**：修改模型 API 与自动化参数。
- **全局开关**：头部「运行中 / 已关闭」按钮控制整个脚本是否执行自动化逻辑。
- **迷你态**：点击右上角收缩按钮可回到迷你图标，点击图标重新展开。

## 已知边界

- 当前只匹配 `*.chaoxing.com`，不面向其他平台。
- 不内置题库，不提供在线搜索兜底。
- 超星页面 DOM 变化可能导致任务点或播放器状态回退到“等待页面数据”。
- 自动答题依赖模型返回格式；模型答错时脚本无法保证答案正确。
